# Информационно-справочная система расписания поездов «РЖД-Инфо»

Веб-ориентированная информационно-справочная система для мониторинга движения пассажирских поездов, контроля расписания, отслеживания станционных табло и формирования маршрутных справок в режиме реального времени.

> **Примечание:** Сервис носит исключительно информационно-справочный характер. Функции онлайн-продажи и бронирования билетов исключены в соответствии с регламентом справочных систем.

---

## 🛠 Технологический стек

* **Язык программирования:** Python 3.12+
* **Бэкенд-фреймворк:** Flask
* **База данных:** Google Cloud Firestore (NoSQL)
* **Интеграция:** Firebase Admin SDK
* **Фронтенд:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Bootstrap Icons
* **Формат календаря:** RFC 5545 (iCalendar / `.ics`)

---

## 📌 Основные возможности

1. **Поиск поездов:**
   * Поиск по станциям отправления и прибытия с выбором даты.
   * Фильтрация по типам поездов: скоростные («Ласточка»), фирменные, пассажирские.
   * Сортировка: по времени отправления, цене или скорости в пути.
   * Автоматический пересчет расписания на актуальные даты (день обращения + 1 день).

2. **Электронное онлайн-табло вокзалов:**
   * Режимы «Отправление» и «Прибытие» для ключевых вокзалов.
   * Отображение номера пути/платформы и статуса рейса в реальном времени.

3. **Справка по маршруту и вагонам:**
   * График промежуточных остановок со временем стоянки.
   * Информационные схемы компоновки вагонов с индикацией свободных и занятых мест:
     * **Купе:** 9 четырехместных купе (верхние и нижние спальные полки).
     * **Плацкарт:** спальные отсеки и боковые полки.
     * **Ласточка:** кресельный салон (места у окна и прохода).
   * Экспорт рейса в файл календаря `.ics`.

4. **Панель управления диспетчера (`/admin`):**
   * Авторизация диспетчера с хешированием паролей.
   * Добавление рейсов в облачную базу данных Firestore.
   * Оперативная смена статусов («Задерживается», «Отменен») и номеров платформ.
   * Удаление рейсов.

🚀 Пошаговая инструкция по работе с проектом
1. Запуск проекта на текущем компьютере
Если проект уже настроен в папке:

PowerShell
cd $HOME\Documents\train_schedule
.\venv\Scripts\Activate.ps1
python run.py
Сайт откроется по адресу: http://127.0.0.1:5000.

2. Развертывание на новом компьютере с нуля
Скачайте репозиторий с GitHub через кнопку Code -> Download ZIP или склонируйте его:

PowerShell
git clone ВАШ_URL_РЕПОЗИТОРИЯ
cd train_schedule
Создайте и активируйте виртуальное окружение:

PowerShell
python -m venv venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
Установите необходимые библиотеки:

PowerShell
pip install Flask firebase-admin python-dotenv werkzeug
Поместите файл сервисного ключа Google Firebase (firebase_key.json) в корень папки train_schedule.

Инициализируйте облачную базу данных:

PowerShell
python seed_db.py
Запустите сервер:

PowerShell
python run.py
3. Отправка изменений на GitHub
Когда в проект внесены правки:

PowerShell
git add .
git commit -m "Описание внесенных изменений"
git push
