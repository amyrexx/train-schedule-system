\ Информационно-справочная система расписания поездов «РЖД-Инфо»



Веб-ориентированная информационно-справочная система для мониторинга движения пассажирских поездов, контроля расписания, отслеживания станционных табло и формирования маршрутных справок в режиме реального времени.



> \\Примечание:\\ Сервис носит исключительно информационно-справочный характер. Функции онлайн-продажи и бронирования билетов намеренно исключены в соответствии с техническим заданием.



\---



\ 🛠 Технологический стек



\ \\Язык программирования:\*\* Python 3.12+

\ \\Бэкенд-фреймворк:\*\* Flask

\ \\База данных:\*\* Google Cloud Firestore (NoSQL)

\ \\SDK интеграции:\*\* Firebase Admin SDK

\ \\Фронтенд:\*\* HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Bootstrap Icons

\ \\Стандарты форматов:\*\* RFC 5545 (iCalendar / `.ics`)



\---



\ 📌 Ключевые функциональные возможности



1\. \\Многокритериальный поиск рейсов:\\

&#x20;  \ Выбор станций отправления и прибытия с фильтрацией по дате поездки.

&#x20;  \ Фильтрация по категориям составов: скоростные («Ласточка»), фирменные экспрессы («Урал», «Демидовский»), пассажирские поезда.

&#x20;  \ Сортировка выдачи: по времени отправления, минимальной стоимости базового тарифа и времени в пути.

&#x20;  \ Автоматическая динамическая проекция дат на актуальные сутки.



2\. \\Электронное онлайн-табло вокзалов:\\

&#x20;  \ Отображение оперативных списков отправления и прибытия по ключевым железнодорожным узлам.

&#x20;  \ Отображение назначенных платформ и текущего статуса состава («По расписанию», «Задерживается», «Отменен»).



3\. \\Справка по маршруту и схемам вагонов:\\

&#x20;  \ Детальный маршрутный лист с указанием промежуточных остановок, времени стоянки и общего времени в пути.

&#x20;  \ Информационный чертеж вагонов с индикацией занятости полок:

&#x20;    \ \\Купейный вагон:\*\* 9 четырехместных купе (верхние и нижние спальные полки).

&#x20;    \ \\Плацкартный вагон:\*\* основные отсеки полок и боковые спальные места.

&#x20;    \ \\Скоростной экспресс («Ласточка»):\*\* кресельный салон (места у окна и у прохода).

&#x20;  \ Экспорт данных о поездке в персональный календарь пассажира (файл `.ics`).



4\. \\Панель управления диспетчера (`/admin`):\\

&#x20;  \ Защищенная служебная авторизация с хешированием паролей (Werkzeug Security).

&#x20;  \ Добавление новых рейсов в облачную базу данных.

&#x20;  \ Оперативное обновление номеров платформ и статусов опоздания поездов.

&#x20;  \ Удаление неактуальных рейсов из расписания.

🚀 Пошаговая инструкция по работе с проектом
1. Запуск проекта на текущем компьютере
Если проект уже настроен в папке:

PowerShell
cd $HOME\Documents\train_schedule
.\venv\Scripts\Activate.ps1
python run.py
Сайт откроется по адресу: http://127.0.0.1:5000.

2. Развертывание на новом компьютере с нуля
Скачайте репозиторий с GitHub через кнопку Code -> Download ZIP или склонируйте его:

PowerShell
git clone ВАШ_URL_РЕПОЗИТОРИЯ
cd train_schedule
Создайте и активируйте виртуальное окружение:

PowerShell
python -m venv venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
Установите необходимые библиотеки:

PowerShell
pip install Flask firebase-admin python-dotenv werkzeug
Поместите файл сервисного ключа Google Firebase (firebase_key.json) в корень папки train_schedule.

Инициализируйте облачную базу данных:

PowerShell
python seed_db.py
Запустите сервер:

PowerShell
python run.py
3. Отправка изменений на GitHub
Когда в проект внесены правки:

PowerShell
git add .
git commit -m "Описание внесенных изменений"
git push
